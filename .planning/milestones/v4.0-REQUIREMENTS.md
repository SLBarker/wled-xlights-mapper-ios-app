# Requirements Archive: v4.0 — Discoverability, Compliance & Performance

**Archived:** 2026-05-18 (milestone complete)
**Original:** .planning/REQUIREMENTS.md (v4.0 cycle)
**Core Value:** Every visitor who arrives on the page should come away understanding what the app does and be able to download it — the page must convert curiosity into App Store taps.

---

## v4.0 Requirements

### Discoverability

- [x] **DISC-01**: Visitor who shares the page URL on social media or chat apps sees a rich preview card with correct title, description, and image — **COMPLETE** (Phase 8-01: OG + Twitter Card meta tags + og-image.png)
- [x] **DISC-02**: Visitor sees the app favicon in the browser tab; iOS user bookmarking the page to home screen sees the Apple touch icon — **COMPLETE** (Phase 8-01: favicon.svg + favicon.png + apple-touch-icon.png; human-verified in Phase 8 UAT)
- [x] **DISC-03**: `robots.txt` allows all search engine crawling; `sitemap.xml` lists the canonical page URL — **COMPLETE** (Phase 9-01)

### Legal

- [x] **LEGL-01**: Page footer contains a visible link to the privacy policy — **COMPLETE** (Phase 8-02: privacy.html + footer link in index.html)

### Performance

- [x] **PERF-02**: Inter typeface loads from GitHub Pages assets; no request is made to `fonts.googleapis.com` or `fonts.gstatic.com` on page load — **COMPLETE** (Phase 10: 4 WOFF2 files in resources/fonts/, @font-face declarations in index.html inline style)

| Formspree / EmailJS | User decided against; mailto is sufficient |
