## Milestone Summary

**Key Decisions:**

- Favicon: dark background `#0a0a0f` (site surface) + `#0071e3` (accent) for WX monogram — consistent with design system; not the teal `#2dd4bf`
- Social description duplicates `<meta name="description">` content for consistency across sharing channels
- privacy.html treated as an acceptable companion file (same static pattern as index.html; CLAUDE.md constraint applies to CSS, not companion pages)
- Effective date for privacy policy: 18 May 2026
- Font loading: WOFF2-only (no WOFF fallback — D-03), Latin subset only (D-02), drop weight 300 (D-01 — never assigned in CSS)
- No `<link rel="preload">` for fonts — `font-display: swap` alone is sufficient (D-05)
- Font file naming: flat `inter-NNN.woff2` — no version suffix, no subfolders
- Font source: gwfh API used for discovery (per-file v13 URLs were stale; actual version was v20 at time of execution)

**Issues Resolved:**

- Google Fonts CDN dependency eliminated — Inter now served from GitHub Pages assets
- robots.txt was previously blocking all crawlers — now opens all paths
- App Store compliance gap (LEGL-01) resolved with privacy policy page

**Issues Deferred:**

- PERF-03: Video compression (3dpreview.mp4 = 9.2 MB) — deferred until final video asset available
- CONT-01: App Store URL for `#download` CTA — blocked until URL is available from Apple
- favicon.png and apple-touch-icon.png required manual rasterization from favicon.svg (human checkpoint — completed in Phase 8 UAT)
- 8 human-verification items (UAT + browser checks) acknowledged at close — code is correct in all cases

**Technical Debt Incurred:**

- privacy.html still imports Inter from Google Fonts CDN (Phase 10 only targeted index.html) — minor; privacy page traffic is negligible and the page is structurally isolated
