| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-08-06 | Spoofing | privacy.html Google Fonts CDN request | accept | Same CDN used in index.html; no new trust boundary introduced; Phase 10 will self-host the font and remove this request |

| T-08-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs in this plan — privacy.html is hand-authored HTML/CSS; no build tooling required |
