# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-14
**Phases:** 1–3
**Total Plans:** 7

## Overview

Three focused phases took the landing page from its original desktop-only, bug-riddled state to a polished, mobile-first page with a conventional carousel hero and a direct user-feedback channel. All 12 v1 requirements shipped. Single-file static architecture maintained throughout.

## Phases

### Phase 1: Mobile & Polish

**Goal:** The page is fully usable on mobile — nav is accessible, videos do not auto-download, and all known copy and markup bugs are eliminated
**Depends on:** Nothing (first phase)
**Requirements:** MOBL-01, MOBL-02, MOBL-03, MOBL-04, MOBL-05, PERF-01
**Plans:** 3 plans

Plans:
- [x] 01-01-PLAN.md — Markup bug fixes (nested DOM, alt text, grammar)
- [x] 01-02-PLAN.md — Mobile responsive CSS + hamburger nav toggle
- [x] 01-03-PLAN.md — Lazy video loading via IntersectionObserver

**Success Criteria (met):**
1. On a 375px viewport a visitor can tap a hamburger icon to open/close nav links and reach any page section ✓
2. All page sections are readable with no clipped or overflowing content at 375px–768px widths ✓
3. Both autoplay videos are not fetched on page load — they load only when scrolled near the viewport ✓
4. Copy reads correctly ("its" not "it's") and every image has accurate, unique alt text ✓

**Completed:** 2026-05-13

**Depends on:** Phase 1
**Requirements:** HERO-01, HERO-02, HERO-03
**Plans:** 2 plans

Plans:
- [x] 02-01-PLAN.md — Remove old hero__phones CSS; add full hero-carousel CSS section
- [x] 02-02-PLAN.md — Replace hero__phones HTML with 4-slide carousel markup + carousel JS IIFE

**Success Criteria (met):**
1. The hero no longer shows a horizontal fan/strip — a single phone mockup is displayed at a time ✓

**Completed:** 2026-05-14

## Milestone Summary

**Key Decisions:**
- mailto for contact section — no backend; Formspree/EmailJS ruled out (✓ implemented)
- Carousel uses existing phone mockup assets — avoids new design work (✓ implemented; fourth slide added)
- Single-file architecture maintained — no split into .css/.js files (✓ maintained throughout)
- Contact section placed before Privacy in nav/page order — user preference (✓ applied Phase 3)

**Issues Resolved:**
- Five nested `.phone-bezel__screen` DOM double-border artefacts fixed
- Four copy-pasted alt text / aria-label descriptions corrected
- Two Step 04 grammar errors ("it's" → "its") fixed
- Mobile nav had no fallback — hamburger nav implemented
- 13.3 MB of video was loaded eagerly — deferred to scroll proximity

**Issues Deferred:**
- App Store link — no URL yet; `#download` CTA remains a placeholder
- `discovery.mov` (4.1 MB unused asset) not cleaned up — deferred to v2

**Technical Debt Incurred:**
- None significant. Single-file approach remains sustainable at 1,755 lines.
