<objective>
Replace the inline `src` attribute on both autoplay `<video>` elements with `data-src`, then add a dedicated IntersectionObserver that writes the `src` back when a video scrolls within 200px of the viewport.

Purpose: Both MP4 files are large (3dpreview.mp4 = 9.2 MB, discovery.mp4 = 4.1 MB). Mobile visitors on cellular connections currently download all 13+ MB before any video is visible. Lazy loading defers that cost until the user actually scrolls to the relevant feature.
Output: index.html with lazy-loaded videos — src deferred via data-src, observer-driven load trigger.

**Step B — JavaScript change: Add lazy video IntersectionObserver**

Add a NEW `<script>` block immediately after the existing hamburger nav `<script>` block (which was added in Plan 02), before the closing `</body>` tag.

```html
<script>
  /* ── Lazy video loading ── */
  (function () {
    var lazyVideos = document.querySelectorAll('video[data-src]');

    if (!lazyVideos.length) return;

    var lazyVideoObserver = new IntersectionObserver(function (entries) {
      entries.forEach(function (entry) {
        if (entry.isIntersecting) {
          var video = entry.target;
          video.src = video.dataset.src;
          video.load();
          lazyVideoObserver.unobserve(video);
        }
      });
    }, { rootMargin: '200px' });

    lazyVideos.forEach(function (video) {
      lazyVideoObserver.observe(video);
    });
  }());
</script>
```

Place this script block verbatim. Do not modify the existing IntersectionObserver animation script or the hamburger script.

The three script blocks in the final file must be in this order:
1. IntersectionObserver animation script (existing — unchanged)
2. Hamburger nav script (added in Plan 02 — unchanged)
3. Lazy video script (new — added in this plan)
