**Replace with this exact code:**
```javascript
function goTo(n) {
  current = ((n % total) + total) % total;
  track.style.transform = `translateX(-${current * 240}px)`;
  dots.forEach((dot, i) => {
    const active = i === current;
    dot.classList.toggle('hero-carousel__dot--active', active);
    dot.setAttribute('aria-current', active ? 'true' : 'false');
  });
  slides.forEach((slide, i) => {
    slide.setAttribute('aria-hidden', i === current ? 'false' : 'true');
    slide.classList.toggle('hero-carousel__slide--active', i === current);
  });
  prevBtn.style.visibility = current === 0 ? 'hidden' : 'visible';
  nextBtn.style.visibility = current === total - 1 ? 'hidden' : 'visible';
}
```

**Exactly three changes from the original:**
1. `100}%` → `240}px` (D-07: pixel-based offset; slide is 240px wide, track-wrap is 380px so percentage no longer maps to one slide)
2. Inside `slides.forEach`, add `slide.classList.toggle('hero-carousel__slide--active', i === current);` on the line after `aria-hidden` (D-08: active class toggle, same pattern as dot toggle above it)
3. After the `slides.forEach` block, add the two `visibility` lines (D-05: hide prev at boundary 0, hide next at boundary total-1)

**Variable names:** `prevBtn` and `nextBtn` are already defined in the IIFE scope (they reference `#carousel-prev` and `#carousel-next`). Confirm their names by reading lines 1692–1707 before editing. If named differently, substitute the actual variable names.

The `goTo(current)` call at line ~1720 (the initial call on page load) will automatically set `prevBtn` to `visibility: hidden` on first render because `current === 0`. No separate initialisation code is needed.
