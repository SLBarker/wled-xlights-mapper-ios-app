## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f5f5f7` (`--bg`) | Page background, main surfaces |
| Secondary (30%) | `#ffffff` (`--surface`) | Cards, nav background (frosted), feature rows |
| Accent (10%) | `#0071e3` (`--accent`) | Interactive links, CTA buttons, favicon "WX" text |
| Dark surface | `#0a0a0f` | Footer background, hero section, favicon background |
| Muted text | `#6e6e73` (`--muted`) | Secondary text, footer text overlay |
| Accent 2 | `#34c759` (`--accent2`) | Privacy section label only |
| Destructive | `#ff3b30` (`--danger`) | Destructive actions only — not used in Phase 8 |

**Accent (#0071e3) is reserved for:**
- Navigation active state / CTA download button
- Privacy Policy link text in footer
- Back link text on `privacy.html`
- SVG favicon "WX" monogram text color
- Inline hyperlinks within `privacy.html` body prose

**Footer link color:** `rgba(255,255,255,0.35)` — matches existing `footer p` rule; Privacy Policy
link text inherits this via the footer `<p>` rule, with the `<a>` using `color: inherit` and an
underline to indicate interactivity. On hover: transition to `rgba(255,255,255,0.7)`.

**`privacy.html` background:** `--bg` (#f5f5f7) for the body; nav bar uses same frosted-glass
pattern as main site (`background: rgba(255,255,255,0.72)`, `backdrop-filter: blur(20px)`).

Source: index.html :root CSS (lines 14–28), footer CSS (lines 1020–1030), CONTEXT.md D-07.

## Component Inventory

Phase 8 introduces no new interactive components. All additions are static HTML elements
following existing markup patterns.

### New Elements (index.html)

| Element | Pattern | Notes |
|---------|---------|-------|
| OG meta tags | `<meta property="og:..." content="...">` | 6 tags in `<head>` |
| Twitter card tags | `<meta name="twitter:..." content="...">` | 4 tags, grouped with OG tags |
| Canonical link | `<link rel="canonical" href="...">` | 1 tag in `<head>` |

| Favicon PNG fallback | `<link rel="icon" type="image/png" href="favicon.png">` | 32×32px fallback |
| Apple touch icon link | `<link rel="apple-touch-icon" href="apple-touch-icon.png">` | 180×180px |
| Privacy Policy link | `<p><a href="privacy.html">Privacy Policy</a></p>` | Last child of `<footer>` |

### New Files

| File | Location | Description |
|------|----------|-------------|
| `favicon.svg` | repo root | SVG monogram — 32×32 viewBox, dark rect + "WX" text |
| `favicon.png` | repo root | PNG fallback — 32×32px rasterized |
| `apple-touch-icon.png` | repo root | 180×180px PNG, same monogram with larger padding |
| `privacy.html` | repo root | Standalone privacy policy page |

### favicon.svg Specification

```
viewBox="0 0 32 32"
Background rect: fill="#0a0a0f", rx="6", full 32×32
Text: "WX", font-family="Inter,system-ui,sans-serif", font-weight="700",
      font-size="14", fill="#0071e3", text-anchor="middle",
      dominant-baseline="central", x="16", y="16"
```

No gradients, no strokes, no shadows. Minimal 2-element SVG.

## Accessibility Contract

- All `<link rel="icon">` elements are in `<head>` — no accessible name required
- Privacy Policy `<a>` must have `aria-label="Privacy Policy for WLED to xLights Mapper"` (distinguishes from the `#privacy` section nav link)
- `privacy.html` nav back link: `aria-label="Back to WLED xLights Mapper landing page"`
- `privacy.html` `<main>` contains all policy content; `<nav>` is separate landmark
- All focus-visible outlines: `2px solid #0071e3`, `outline-offset: 2px` — meets WCAG 2.1 AA
