<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTML head → social platforms | OG/Twitter meta tags are consumed by crawlers (Slack, Twitter/X, iMessage) — content is read-only static strings, no user input |
| Repo root → browser | favicon.svg, favicon.png, apple-touch-icon.png are served as static assets — no executable content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | og:image absolute URL | accept | URL points to a repo-owned static asset at a known path; no redirect chain; no private data exposed |
| T-08-02 | Spoofing | og:title / og:description content | accept | Content is static strings matching existing page title and description; no user-supplied values involved |
| T-08-03 | Tampering | favicon.svg served as image/svg+xml | accept | SVG contains no script elements, no foreignObject, no href links — purely presentational rect + text; no XSS vector |
| T-08-04 | Information Disclosure | canonical URL exposed in HTML | accept | Canonical URL is the public GitHub Pages URL, already implied by the page being publicly hosted; no new information |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs in this plan — favicon.svg is hand-written; PNG generation uses system tools only |
</threat_model>
