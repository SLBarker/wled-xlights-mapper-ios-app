## Color

All color values come from existing `:root` tokens. No new colors are introduced.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg)` #f5f5f7 | Page background; `.stepper` wrapper background |
| Secondary (30%) | `var(--surface)` #ffffff | `.stepper__panel` background; active tab background |
| Accent (10%) | `var(--accent)` #0071e3 | Step number badge fill; active tab indicator underline/border; phase eyebrow label |
| Muted | `var(--muted)` #6e6e73 | Inactive step title text in rail; detail body text |
| Text | `var(--text)` #1d1d1f | Active step title text; step content headings |
| Destructive | `var(--danger)` #ff3b30 | Not used in this phase |

Accent reserved for:
1. Step number badge background (28×28px circle, white numeral)
2. Active tab bottom border indicator (desktop rail, 2px solid underline)
3. Phase eyebrow label text (`.workflow__phase-title`)

Accent is NOT applied to: inactive tab text, panel backgrounds, body text, or borders.

Additional color notes:
- Inactive tab: background transparent, text `var(--muted)`, no border indicator
- Active tab: background `var(--surface)`, text `var(--text)`, 2px bottom border `var(--accent)`
- Panel: background `var(--surface)`, box-shadow `var(--shadow)` (0 4px 32px rgba(0,0,0,0.08)), border-radius `var(--radius-sm)` (16px)
- Step number badge when inactive: background `var(--muted)` — visually de-emphasises unselected steps
- Step number badge when active: background `var(--accent)` — signals current focus

## Component: .stepper

This section defines the complete BEM contract for the new stepper component.

### BEM Structure

```
.stepper
  .stepper__rail                    — horizontal flex container of tab buttons (desktop) / hidden (mobile)
    .stepper__step                  — wrapper for one step in the rail
      .stepper__tab                 — button element (focusable); active state: .stepper__tab--active
        .stepper__badge             — step number circle
        .stepper__title             — step title text
  .stepper__panel                   — detail area below the rail (desktop) / per-step (mobile)
    .stepper__body                  — flex row: media column + content column
      .stepper__media               — phone bezel slot (optional; absent = .stepper__body--text-only)
      .stepper__content             — text: step heading + description paragraphs

Mobile accordion variant (≤767px):
.stepper
  .stepper__item                    — wraps header + panel for one step
    .stepper__header                — button; active: .stepper__header--active
      .stepper__badge
      .stepper__title
    .stepper__panel                 — height:0 / overflow:hidden when collapsed; auto when expanded
      .stepper__body
        .stepper__media             (optional)
        .stepper__content
```

### Desktop Layout (≥768px)

- `.stepper__rail`: `display:flex; gap:0; border-bottom: 1px solid rgba(0,0,0,0.08);`
- `.stepper__step`: `flex:1;` — all tabs share equal width across the rail
- `.stepper__tab`: `width:100%; padding:12px 16px; display:flex; align-items:center; gap:8px; background:transparent; border:none; border-bottom:2px solid transparent; cursor:pointer; transition: border-color var(--transition), color var(--transition), background var(--transition);`
- `.stepper__tab--active`: `background:var(--surface); border-bottom-color:var(--accent); color:var(--text);`
- `.stepper__tab--active .stepper__badge`: `background:var(--accent);`
- `.stepper__badge`: `width:28px; height:28px; border-radius:50%; background:var(--muted); color:#fff; font-size:0.75rem; font-weight:600; display:flex; align-items:center; justify-content:center; flex-shrink:0;`
- `.stepper__title`: `font-size:0.9375rem; font-weight:600; line-height:1.3; text-align:left;`
- `.stepper__panel`: `background:var(--surface); border-radius:0 0 var(--radius-sm) var(--radius-sm); box-shadow:var(--shadow); padding:24px;`
- `.stepper__body`: `display:flex; gap:24px; align-items:flex-start;`
- `.stepper__body--text-only .stepper__content`: `flex:1;` — text fills full width when no media present
- `.stepper__media`: `flex-shrink:0; width:240px;` — positions the `.phone-bezel` child
- `.stepper__content`: `flex:1; min-width:0;`

### Mobile Layout (≤767px)

- `.stepper__rail`: `display:none;` — rail hidden; accordion items render instead
- `.stepper__item`: `border-bottom:1px solid rgba(0,0,0,0.08);`
- `.stepper__header`: `width:100%; padding:16px 0; display:flex; align-items:center; gap:8px; background:none; border:none; cursor:pointer; text-align:left;`
- `.stepper__header--active .stepper__badge`: `background:var(--accent);`
- `.stepper__header--active .stepper__title`: `color:var(--text);`
- `.stepper__panel` (collapsed): `height:0; overflow:hidden; transition:height var(--transition);`
- `.stepper__panel` (expanded): `height:auto;` — Phase 7 will drive this via JS; Phase 6 sets static open state on first item via CSS `:first-child` rule
- First item open by default (CSS only, no JS in Phase 6): `.stepper__item:first-child .stepper__panel { height:auto; }` and `.stepper__item:first-child .stepper__header .stepper__badge { background:var(--accent); }`
- On mobile, `.stepper__body` switches to `flex-direction:column;` — phone bezel stacks above text
- `.stepper__media` on mobile: `width:180px; margin:0 auto 16px;` — scaled-down bezel, centred

## Interaction Contract (Static — CSS Only)

Phase 6 covers static structure. The following defines what CSS must support for Phase 7 to layer JS on top without structural changes.

| Interaction | Phase 6 responsibility | Phase 7 responsibility |
|-------------|----------------------|----------------------|
| Show all step titles at a glance | Render full rail on desktop; render all accordion headers on mobile | n/a |
| Active tab highlight | CSS class `.stepper__tab--active` / `.stepper__header--active` — style defined | JS adds/removes the class |
| Panel expand (desktop) | Panel is always visible; JS swaps content | JS swaps content on click |
| Panel expand (mobile) | First item's panel has `height:auto` via `:first-child` CSS | JS toggles height + active class on click |
| Panel collapse (mobile) | `height:0; overflow:hidden` is the default non-active state | JS removes open class |
| Transition | `transition:height var(--transition)` on `.stepper__panel` — smooth for JS-driven changes | JS triggers by class toggle |

## Accessibility Contract

- All `.stepper__tab` and `.stepper__header` elements are `<button>` elements — keyboard focusable by default
- `aria-expanded` attribute on each button: Phase 7 adds JS; Phase 6 sets static `aria-expanded="true"` on the first item's header, `aria-expanded="false"` on all others
- `aria-controls` on each button pointing to the corresponding panel `id` — HTML structure must include IDs in Phase 6
- Focus ring: `outline: 2px solid var(--accent); outline-offset: 2px;` on `:focus-visible` — matches existing pattern in the codebase
- Colour contrast: `var(--text)` (#1d1d1f) on `var(--surface)` (#ffffff) = 16.1:1 (AAA). `var(--muted)` (#6e6e73) on `var(--surface)` (#ffffff) = 4.6:1 (AA Large). Both pass WCAG 2.1 AA.
